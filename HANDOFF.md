# Передача проекта в Claude Code

## 1. Подготовка (один раз)
1. Создайте папку проекта, например `tcm-landing`, и положите в неё:
   - `DESIGN.md`
   - `ASSETS.md`
   - папку `materials/` с подпапками `images/`, `models/`, `video/` (пока можно пустую)
2. Откройте в этой папке Claude Code **под той же учётной записью claude.ai**, где создан макет. Макет приватный, с другой учётной записи он не прочитается.

## 2. Ссылка на макет
https://claude.ai/artifact/GkM5UpD8CZhcNHydtCiiRs

Claude Code умеет читать такие страницы своим инструментом Artifact (действие read): он видит всю вёрстку, цвета, тексты и порядок секций.

## 3. Стартовый запрос (вставить в Claude Code)

```
Собери лендинг по DESIGN.md и макету: https://claude.ai/artifact/GkM5UpD8CZhcNHydtCiiRs
Сначала прочитай макет через инструмент Artifact (read) и файл ASSETS.md.

Стек: Vite + React + TypeScript + Tailwind + Motion. Только русский язык.

Правила:
- Тексты, цвета, шрифты (Cormorant Garamond для заголовков, Onest для текста) и порядок секций бери точно из макета.
- Бамбук по бокам делай в SVG и CSS с анимацией: рост при загрузке, покачивание, лёгкий параллакс. Уважай prefers-reduced-motion.
- Шапка полупрозрачная с размытием, прилипает к верху.
- Название компании, логотип, телефон, email, город, фото специалиста, видео 9:16, сертификаты, картинки и 3D-модели: заглушки, вынесенные в один файл конфигурации. Материалы будут лежать в materials/ (images, models, video), пока их нет, показывай заглушки.
- Иконки: пакет lucide-react вместо рисованных.
- Форму заявки не делай, вместо неё кнопки-заглушки с контактами.
- Адаптив: сначала телефон. Бамбук на узких экранах сужается до тонкой полосы.
- Не публикуй персональные данные специалиста (номер удостоверения, дата рождения, номер сертификата).
- Медицинские формулировки оставляй мягкими, как в макете.

Порядок:
1. Каркас, дизайн-токены, шрифты, бамбуковые коридоры.
2. Секции 1-12 со статичным контентом.
3. Анимации (Motion), затем эффекты.
4. Слот 3D для hero (react-three-fiber или встраивание сцены Spline), когда появятся модели.
5. Проверка на мобильных, производительность, сборка.
После каждого шага коротко пиши, что сделано, и запускай dev-сервер.
```

## 4. Когда появятся материалы
Положите файлы в `materials/` и напишите Claude Code: «Подставь материалы из materials/ вместо заглушек по ASSETS.md».

## 5. Если Claude Code не может открыть ссылку
- Проверьте, что вход выполнен под той же учётной записью.
- Запасной путь: скачайте макет со страницы макета (меню «Поделиться» / «Экспорт», точное название может отличаться) и положите файл в папку проекта. Тогда в запросе замените ссылку на путь к файлу.
