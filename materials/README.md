# Материалы от клиента

Положите файлы сюда, имена — как в `ASSETS.md` (латиницей):

- `images/` — `logo.svg`, `specialist.webp`, `cert-1.webp` … `cert-3.webp`,
  `women.webp`, `ink-landscape.webp`, `method-*.webp`, `og.jpg`
- `models/` — `.glb` (баночка, моксо-стик, иглы, нефритовый диск, камни)
- `video/` — `intro.mp4` (вертикальное 9:16) + `intro-poster.webp`

Дальше: скопировать в `public/` и прописать пути в `src/site.config.ts`
(см. README в корне проекта).

**Перед публикацией сертификатов** закрыть номер удостоверения личности,
дату рождения и номер сертификата.
