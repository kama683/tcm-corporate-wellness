# Лендинг «Корпоративная программа ТКМ»

Vite + React + TypeScript + Tailwind v4 + Motion. Только русский язык.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/ — любой статический хостинг
npm run preview  # посмотреть собранную версию
```

## Где что лежит

| Путь | Что это |
|---|---|
| `src/site.config.ts` | **Единственный файл с заглушками**: телефон, данные специалиста, видео, сертификаты, картинки, 3D-модели, меню |
| `src/index.css` | Дизайн-токены (палитра, шрифты) и бамбуковые коридоры |
| `src/components/Bamboo.tsx` | Бамбук по бокам: рост при загрузке, покачивание, параллакс, индикатор прокрутки |
| `src/components/HeroScene.tsx` | Слот под 3D-сцену hero |
| `src/components/Reveal.tsx` | Появление блоков (каскадом в режиме презентации, по скроллу в обычном) |
| `src/lib/sections.tsx` | Реестр секций: порядок, якоря, подписи, вид перехода |
| `src/hooks/useSectionScroll.ts` | Покадровая навигация: колесо, клавиатура, свайпы, якоря |
| `src/lib/transitions.ts` | Переходы между секциями |
| `src/components/Deck.tsx` | Режим презентации |
| `src/components/Flow.tsx` | Обычная прокрутка (телефоны, reduced-motion) |
| `src/sections/` | Секции страницы в порядке макета |
| `src/materials/` | Исходники от клиента (`images/`, `video/`) |
| `src/assets/optimized/` | Сжатые версии: WebP, видео, og-картинка |
| `src/config/assets.ts` | Пути ко всем материалам — единственное место |

Порядок секций задан в `src/lib/sections.tsx`: Hero → Зачем это компании →
Методы → Специалист → Направления → Программа → Для женщин → Стоимость →
Организация → Для руководства → Безопасность → Финальный блок (вместе с
футером). Чтобы переставить, добавить или убрать секцию, правится только
этот файл.

## Навигация: два режима

**Режим презентации** (экраны от 768 px, без `prefers-reduced-motion`):
один экран — одна секция.

| Управление | Действие |
|---|---|
| Колесо, тачпад | Один жест — одна секция. Инерция тачпада не перелистывает лишнего |
| `↑` `↓` | Секция вперёд/назад (сначала прокручивают контент внутри секции) |
| `PageUp` `PageDown` `Space` | То же, шагом в экран |
| `Home` `End` | Первая и последняя секция |
| Свайп вверх/вниз | Телефон и планшет |
| Кнопка внизу | Следующая секция; на последней — «наверх» |
| Точки справа | Переход к секции, подпись при наведении |
| Ссылки в шапке, `#якоря` | Плавный переход, адрес в строке обновляется |

Каждая секция помещается в один экран целиком. Если содержимое не влезает
(невысокое окно), оно пропорционально уменьшается — `useFitScale`
в `src/hooks/useFitScale.ts`. Ниже масштаба 0.68 вместо уменьшения
включается внутренняя прокрутка: колесо листает содержимое и переключает
секцию только на краю.

Плотность отступов в режиме презентации задаётся одной переменной
`--spacing` на `.deck-pane` в `src/index.css`: от неё считаются все поля,
отступы и зазоры Tailwind.

**Обычный режим** (экраны уже 768 px или `prefers-reduced-motion`):
вертикальная прокрутка с лёгким scroll-snap и появлением блоков по скроллу.
Переключение между режимами происходит само при изменении ширины окна.

Переходы: уходящая секция уменьшается, размывается и уходит с затуханием,
новая выезжает с лёгким масштабированием; внутри секции элементы появляются
каскадом. У hero, «Специалиста» и финального блока — круговое раскрытие
(`clip-path`). Всё на Motion, без внешних fullpage-библиотек.

## Как подставить материалы

1. Положить исходники в `src/materials/images`, `src/materials/video`
   (имена — как в `ASSETS.md`).
2. Сжать картинки в WebP (исходники не трогаем) в `src/assets/optimized`.
   Лимиты: карточки методов и «Для женщин» до 250 КБ, пейзаж до 400 КБ.
3. Добавить путь в `src/config/assets.ts` — это единственное место, где
   перечислены материалы. Файл импортируется через Vite и хешируется.
   Компоненты берут пути только оттуда.

Пока значение `null` — на месте материала показывается заглушка с пунктирной
рамкой.

## 3D-сцена hero

`src/components/HeroScene.tsx` — слот. Когда появятся модели:

- **Spline:** `npm i @splinetool/react-spline`, прописать
  `models.heroSplineUrl` в конфиге и отрендерить `<Spline scene={url} />`
  вместо заглушки (лениво, через `React.lazy`).
- **GLB:** `npm i three @react-three/fiber @react-three/drei`, прописать
  `models.hero` и собрать сцену в этом же файле.

На узких экранах и при `prefers-reduced-motion` сцена не инициализируется —
показывается статичная заглушка/постер.

## Анимации и доступность

Все анимации уважают `prefers-reduced-motion`: режим презентации не
включается, бамбук и листья статичны, появления по скроллу отключены,
таймлайн не «рисуется», счётчики цен сразу показывают итоговое число.

Фокус и `Tab` работают в обычном порядке, у кнопок навигации есть
`aria-label`, номер текущей секции объявляется через `aria-live`
(«Секция 3 из 12: Методы»).

Бамбук по бокам не перелистывается вместе с секциями. Правый край —
индикатор прогресса: заполняется по мере перехода, узлы отмечают секции.

## Чего в проекте нет

- **Формы заявки.** Вместо неё в финальном блоке и в шапке кнопка с
  телефоном (`contact` в `src/site.config.ts`).
- **Логотипа и названия компании.** По решению заказчика их нет: в шапке
  только меню и телефон.
- **Футера.** Убран. Медицинский дисклеймер перенесён вниз финального
  блока — он нужен для рекламы медуслуг.
- **Персональных данных специалиста.** Номер удостоверения, дата рождения и
  номер сертификата на сайт не выводятся; на сканах сертификатов их нужно
  закрыть до публикации.
- **Выдуманных фото «врачей».** Только реальные материалы от клиента.
